# CLAUDE. — Motion Design Reel 2026

A 15-second showreel, 1920×1080 at 60 fps, where every frame and every sound
is generated by code. No keyframe editor, no stock footage, no samples, no
video models: a timeline of easing curves, shaders and a numpy synthesizer.

**Watch:** [`claude-showreel.mp4`](claude-showreel.mp4)

The music is 128 BPM, so 8 bars last exactly 15.000 s. Each chapter is one bar,
and every cut, hit and flourish sits on that beat grid, in picture and sound.

| # | Time | Chapter | What it shows |
|---|------|---------|---------------|
| 01 | 0:00.00 | Ignition | A dot builds an instrument: ruler crosshairs, a degree dial, a golden-angle phyllotaxis bloom. It inhales, then irises open on the downbeat. |
| 02 | 0:01.88 | Kinetic type | FORM rises while its width axis animates per letter. FOLLOWS snakes in along a wave. MOTION stomps down letter by letter with squash and stretch. The camera then dives through the counter of the O. |
| 03 | 0:03.75 | Geometry | A Bauhaus quarter-disc grid. Three rotation waves re-tile it on the beat and a 3D flip recolours it, then every disc is reeled into one circle. |
| 04 | 0:05.63 | Particles | 14,000 particles, each a closed-form function of time: a drag-damped explosion, a tilted spiral galaxy with differential rotation, then a Fibonacci sphere. |
| 05 | 0:07.50 | 3D / glass | A raymarched SDF blob in front of marquee type. Two refractions invert the type like a real lens ball, with dispersion and Beer–Lambert tint. Metaball satellites bud off on the half-time hits, then the camera dives into the glass. |
| 06 | 0:09.38 | Shader | One domain-warped fluid field seen four ways: flow, isolines, halftone and datamosh. Diagonal wipes on the beat swap the style. |
| 07 | 0:11.25 | Rhythm | MAKE / IT / MOVE. Split screens re-render the earlier chapters live. Cuts accelerate from quarters to sixteenths, then half a beat of silence. |
| 08 | 0:13.13 | Ident | The opening dot bursts into the name, hops across the letters (which dip under its weight) and lands as the full stop. |

## How it is made

- **Renderer** (`src/`): each scene is a pure function of time drawing into a
  CPU Canvas 2D layer and/or a WebGL2 shader layer, running in headless Chromium.
- **Motion blur is temporal, not a filter.** Each output frame integrates 6–12
  sub-frames across a virtual 216° shutter. The sub-frames are accumulated in
  linear light in a half-float buffer, so bright streaks keep their energy.
  900 frames took 8,322 scene renders.
- **Post** (`src/gl.js`): bloom (dual-filter mip chain), radial chromatic
  aberration and barrel distortion driven by musical impacts, exposure and
  white flashes, vignette, film grain and TPDF dither.
- **Type engine** (`src/type.js`, `tools/build_glyphs.py`): glyph outlines are
  exported with HarfBuzz at each variable-font master and interpolated in the
  browser, so width and weight animate continuously per letter. Interpolation
  matches HarfBuzz to within 0.02 font units.
- **Camera**: impacts drive a noise-based shake per sub-frame. The dive through
  the O is one log-space zoom shared by chapters 02 and 03, so it continues
  across the cut.
- **Soundtrack** (`audio/synth.py`): F minor, i–VI–III–VII. Kick, clap, hats,
  a supersaw pad, sidechained bass, plucks, FM bells and all effects are
  synthesized in numpy. The mix uses a convolution reverb on a synthetic
  impulse response, a ping-pong delay, a beat-repeat stutter, a master EQ
  voiced for small speakers and a look-ahead limiter. It lands at −14 LUFS
  integrated with true peaks under −1 dBTP.

## Build

Requirements: Node 22, Python 3 with `numpy scipy pyloudnorm uharfbuzz
fonttools imageio-ffmpeg`, and Playwright's Chromium.

```bash
npm install                      # playwright
tools/render-all.sh              # glyphs → soundtrack → frames → claude-showreel.mp4
```

Useful while iterating:

```bash
npm run glyphs                   # re-export glyph data after changing fonts/charset
npm run audio                    # re-synthesize assets/soundtrack.wav
node tools/render.mjs --sheet 0:900:30 --cols 6      # contact sheet → render/sheet.png
node tools/render.mjs --stills 120,480 --samples 2   # full-res stills → render/stills/
```

A full render takes about 25 minutes on 4 CPU cores with software WebGL.
