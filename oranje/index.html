One-time setup

Google only hands health data to an app you have registered yourself. It takes about five minutes, once.

  1. In Google Cloud Console, create a project and enable the Google Health API.
  2. Set up the consent screen as External, add yourself under Audience → Test users, and add the Google Health read scopes under Data access.
  3. Create an OAuth client ID of type Web application with this page as an authorised JavaScript origin:
  4. Paste the client ID here.

A client ID is not a secret. It is kept in this browser only.

  • Strain 0–21 from every minute of heart rate, on a published model.
  • Nothing leaves your browser. No server reads or stores your health data.
  • Read-only. Oranje can never change what is in Google Health.
